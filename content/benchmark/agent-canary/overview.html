05 / EVALUATION METHODS

Defined metrics. Traceable findings.

Download results · JSON ↓
01 / OUTCOME

OSS Outcome security

Average outcome assessment, scaled to 0–100. Higher scores indicate more secure outcomes.

UOR = P(raw OSS ≤ 0.5)
02 / AWARENESS

SAS Security awareness

Average security awareness assessment, scaled to 0–100. Measures whether the agent recognizes security risks.

SAR = P(raw SAS ≥ 0.7)
03 / UTILITY

TUS Task utility

Average task utility assessment, scaled to 0–100. Calculated only over samples with a utility assessment.

TSR = P(raw TUS ≥ 0.7)

Evaluation scopeThe leaderboard compares 12 models. Trace analysis covers 11,435 records from 11 models and 438 tasks; the two views have different coverage.

Reading the scoresScores are displayed on a 0–100 scale; thresholds apply to the raw 0–1 scale. A dash means a metric is not reported for that condition. Overall is not a simple average of the group scores.
