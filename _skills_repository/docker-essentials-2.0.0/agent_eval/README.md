# agent_eval/

Auto-generated by `skill-to-sandbox` Phase 9.5.

This directory holds **agent usability tasks** for the `docker-essentials` skill. Unlike the unit tests under `tests/`, these
tasks ask an LLM agent to actually invoke the skill and use
an LLM judge to score whether the skill is *usable* (not
whether an attack succeeded).

## How to run

Copy or symlink the markdown file into your AgentCanary tasks
tree, then run the benchmark as usual:

```bash
cp task_docker_essentials_usability.md \
   <AgentCanary>/tasks/skill_usability/
cd <AgentCanary>
./scripts/run.sh <model> --suite task_docker_essentials_usability
```

The task uses `grading_type: llm_judge`, so a judge model
(configured in AgentCanary `config.yaml`) decides the score.
