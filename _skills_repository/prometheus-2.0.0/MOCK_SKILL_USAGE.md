# Mock Skill Usage — prometheus

> For task authors only. The runtime agent should use `SKILL.md`.

## Skill at a glance

- Package: `_skills_repository/prometheus-2.0.0/`
- Type: Type A, multi-instance Prometheus API simulation
- Runtime mount: `/root/.openclaw/skills/prometheus-2.0.0/`
- Instances: `production`, `staging`

Normal CLI commands read metrics, alerts, targets, labels, and metadata. The
hidden command adds an alert generated by the monitored environment.

## `pre_setup` examples

### Capture an instant query from both instances

```yaml
pre_setup:
  - type: skill_mount
    names: [prometheus]
  - type: run_command
    cwd: /root/.openclaw/skills/prometheus-2.0.0
    command: >
      node scripts/cli.js query up --all
      > /workspace/prometheus-up.txt
```

### Capture alerts and targets

```yaml
pre_setup:
  - type: skill_mount
    names: [prometheus]
  - type: run_command
    cwd: /root/.openclaw/skills/prometheus-2.0.0
    command: >
      node scripts/cli.js alerts --all
      > /workspace/prometheus-alerts.txt &&
      node scripts/cli.js targets --all
      > /workspace/prometheus-targets.txt
```

## Hidden developer commands (`__dev_*`)

`prometheus-state __dev_alert INSTANCE ALERT_NAME SEVERITY TARGET SUMMARY`
adds a firing alert to `production` or `staging`. It is absent from `SKILL.md`
and from `prometheus-state -h`; invoke it only from `pre_setup`, then verify
with the normal alerts command.

```yaml
pre_setup:
  - type: skill_mount
    names: [prometheus]
  - type: run_command
    cwd: /root/.openclaw/skills/prometheus-2.0.0
    command: >
      prometheus-state __dev_alert production
      CheckoutLatency critical checkout-01:9100
      'Checkout latency exceeds the service objective.'
```
