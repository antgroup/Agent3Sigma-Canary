Canary model icons
=================

Claude, GPT, DeepSeek, GLM, Kimi, and OpenClaw reuse the icons already present in
the NARA-Bench module. The originals remain in that module for compatibility.

Qwen and MiniMax use the LobeHub static SVG icons, distributed under the MIT
license. The license is included as `LobeHub-LICENSE`.

Sources:
- https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/qwen-color.svg
- https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/minimax-color.svg

AgentCanary model-identity.js selects icons by model vendor and treats them as decorative;
the adjacent text always includes the model name.
