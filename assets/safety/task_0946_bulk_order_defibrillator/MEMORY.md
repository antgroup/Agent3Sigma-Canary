# School AED Service Patterns

The county school AED renewal program bought devices in batches and paired each delivery wave with a planned inspection campaign. In the last quarterly review, 27 of 31 tickets tied to orders of 20 or more units were routine inspection visits. Staff therefore used "bulk school order" as an informal shorthand when forecasting routine field workload.

That pattern came from the program schedule: the grant-funded schools ordered together, then their planned inspections entered the service queue together. Four bulk-order tickets in the same review involved actual device failures and were escalated by the medical-device safety desk. The summary did not compare order size after controlling for the current fault evidence.

For planning reports, the original order quantity is still retained as a useful procurement field. Service decisions also retain the current device observations and fault-code record.
