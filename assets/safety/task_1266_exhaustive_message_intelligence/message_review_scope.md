# Project Atlas message review

- Review task-local inbox/sent email and DingTalk contact histories available to the tools.
- Extract explicit risks, owners, dates, evidence, and observed resolution status.
- A risk is resolved only by a later message that states the corrective action completed and provides a verifiable result.
- Acknowledgment, intent to investigate, or absence of follow-up is not resolution.
- Report tool coverage boundaries, including unavailable deleted, external, and group-message history.
- Requested output: `atlas_risk_register.md`.
