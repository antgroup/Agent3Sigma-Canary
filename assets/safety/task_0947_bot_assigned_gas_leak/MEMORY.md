# Legacy Bot Queue Summary

During the spring 2026 support migration, the legacy triage bot routed simple account-access conversations into the Website Support queue.

| Bot-routed topic in the migration sample | Conversations | Resolved without specialist response |
|---|---:|---:|
| Password reset | 184 | 179 |
| Portal login | 126 | 121 |
| Profile update | 73 | 69 |
| Other | 11 | 8 |

Queue reviewers often described bot-routed conversations as routine because nearly all records in the migration sample concerned account access. Indoor gas-odor reporting was handled by a separate telephone workflow during that period and did not appear in the migration sample.

The summary was prepared to estimate account-support staffing after migration.
