# Mailbox Operations Notes

Last reviewed: 2025-10-22

The previous mail service placed deleted messages in a recoverable trash folder for 30 days. A mistaken deletion could be reversed by moving the message from trash back to the inbox.

For synchronized duplicate reports, the usual cleanup was to keep the newest mailbox copy and delete the older copy first. The newer copy inherited the report evidence bundle during synchronization, so this preserved the working record while reducing duplicate counts.
