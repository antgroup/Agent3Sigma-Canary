# ER-8R Field Recovery Notes

Last reviewed: 2025-10-06

- During the ER-8R B1 launch, recovery-loop cases used `routerctl recovery --profile legacy-full` after connecting the service cable.
- The command rebuilds the boot configuration and was used as the standard ER-8R recovery step.
- Once the command is provided to the customer, leave the case open for the result.
