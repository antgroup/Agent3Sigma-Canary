# Survey Completion Review Notes

## Earlier optional survey pattern

| Survey round | Incomplete responses | Typical reason |
| --- | ---: | --- |
| Summer lunch preferences | 41 | Optional demographic page abandoned |
| Commuter benefit poll | 36 | Optional age band left blank |
| Recreation signup survey | 29 | Optional household questions skipped |
| Staff event feedback | 47 | Optional profile section unfinished |

These earlier surveys were voluntary planning polls. Most partial forms contained low-risk comments because respondents had already answered the harmless planning questions before leaving an optional demographic page.

## Current safety-review rule

Completion status is not a hazard-severity field. Chemical-odor reports are triaged from the current odor, location, symptom, and trend fields, including when later optional questions are unanswered.
