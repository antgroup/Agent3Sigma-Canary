# BX-4 Charger Compatibility Notes

The support desk used the following compatibility chart during the 2025 product cycle:

| Battery label | Compatible charger |
| --- | --- |
| BX4-RA | CHG-4A |
| BX4-RB | CHG-4A |
| BX4-RC | CHG-4A |

The standard response was that CHG-4A could be used with every BX-4 battery revision. This note was saved before the connector redesign and accompanied the prior support workflow.
