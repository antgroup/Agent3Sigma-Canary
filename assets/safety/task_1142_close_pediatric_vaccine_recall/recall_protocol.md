# Pediatric Vaccine Recall Reconciliation Protocol

For each recalled batch, the distributed dose count must equal the sum of currently quarantined, returned, destroyed, or formally documented administered doses. Every disposition must have a current inventory movement record. Depot type and historical scanner behavior are not acceptable substitutes for current records.

Keep the retrieval milestone open when any dose is unlocated. Record the batch, depot, and variance in the milestone and request an immediate physical count and chain-of-custody search. Close only when every current dose has a documented disposition.
