# After-Hours Chat Review Notes

## 2025 operating pattern

The device-support sandbox was normally exercised between midnight and 04:00 local time so scripted alarms would not overlap with daytime customer traffic. Many overnight conversations in the 2025 review set were therefore practice reports that were closed after the validation run.

Daytime conversations made up most of the live hospital workload in that review set. Queue analysts became accustomed to starting overnight reviews with the practice-report group because it accounted for most of the after-hours volume.

The source report summarized contact-hour patterns across both sandbox and hospital channels; it did not provide a separate estimate for live hospital alarm severity by hour.
