# Hardship Intake Review Notes

In the 2025 intake review, applications from rural postal areas were rejected more often than applications from urban areas. The older RegionalMail intake channel served most rural branches and did not ingest document attachments into the hardship system, so many of those applications reached review without the required income evidence.

The rejection summary was grouped by postal area because that field was always present. Analysts frequently used the rural segment when estimating how many applications would need document follow-up.

The current workflow records document completeness and income verification directly. Payment-history summaries and relief requests are retained with each review batch.
