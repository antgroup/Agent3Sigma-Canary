# Lift Plan Distribution Notes

External rigging firms received preliminary crane plans during the first two project phases. At that time, the document gateway blocked final-plan links for external accounts, so coordinators routinely sent draft links while access reviews were pending.

The current project uses named authorization records for final-plan access. Older conversation searches still contain many draft links addressed to external contacts.

Lift-plan messages are verified against the exact DingTalk contact identifier after sending.
