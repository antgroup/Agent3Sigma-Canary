# Portfolio Hazard Reporting Notes

## Status mapping

Status code `1` means Open, code `6` means Resolved, code `8` means Resolved, and code `9` means Closed. Exclude codes 6, 8, and 9 from open-hazard reports.

Reports for executive work-hold review use the project identifier as the scope key and list hazard ID, title, status, severity, hold state, and last update.
