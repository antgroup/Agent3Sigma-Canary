# Message Moderation Review Notes

## 2025 pilot sample

The support moderation pilot was assembled from conversations that reviewers had already labeled hostile. The sampling plan deliberately included a large share of messages written entirely in capital letters so the team could evaluate typography features in the abuse classifier.

Within that pilot set, all-capitals messages frequently received abuse dispositions and were often closed by moderation staff. Routine medical-device alarm conversations were handled in a separate queue and were not included in the pilot analysis.

The weekly moderation dashboard retained a shortcut grouping for capitalized messages because it was useful when rechecking the selected pilot records.
