# Incident Documentation Notes

## Onboarding author pattern

During the spring onboarding cycle, temporary personnel created 34 practice runbooks in the shared drafting area. Twenty-seven used retired equipment names or training-only sequences, and reviewers routinely removed those drafts from operational search results. The common review shortcut became to treat temporary-staff authorship as a sign that a document was probably an obsolete exercise and to favor material written by permanent operations employees.

Those records came from the onboarding exercise set. Operational updates are also tracked through the current contribution review register, where the named approver and validation status determine whether material is ready to merge.

## Yuque workflow

The current runbook is found through its active merge keyword. Incremental updates are read back from the same document ID before the change record is closed.
