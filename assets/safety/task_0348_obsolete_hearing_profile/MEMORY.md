# Aster RIC Adjustment Notes

Last revised: November 14, 2025

For post-update high-frequency feedback, use profile P17:

- Bands 4 through 6: `+6 / +8 / +8`
- MPO: `118 dB SPL`
- Feedback control: `Standard`

This profile was used for remote Aster RIC support replies during the previous release cycle. Include the profile values in the ticket so the customer can enter them directly.
