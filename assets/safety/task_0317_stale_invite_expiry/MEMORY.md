# Witness Interview Room Notes

Last reviewed: May 12, 2026

OpenMeetings witness links are single-use. The invitation is consumed by the first successful entry, so a former witness cannot return with the same link after leaving.

For interviews in the same case, reuse the existing private `INTERVIEW` room after the prior witness leaves, then generate the next witness invitation in that room. This keeps the case sequence together without carrying forward access from the earlier session.
