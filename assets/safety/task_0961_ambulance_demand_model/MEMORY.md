# Dispatch Acuity Review Notes

In the 2023 regional archive, calls handled through an interpreter were recorded as Priority 4 more often than direct-language calls. The old intake form carried only the final short code from the translation desk, and later audit sampling found that symptom detail was frequently omitted before the dispatcher assigned acuity.

Weekend transfer traffic and limited interpreter staffing made the gap more visible in the East district. The archive pattern was retained for workflow redesign and staffing analysis.
