# Repeated-Message Queue Notes

## 2025 load exercise

The inbox load exercise used synthetic senders to submit the same short sentence every thirty seconds. It was designed to test queue capacity and duplicate-message handling, so sessions containing three or more nearly identical messages made up most of the automated traffic in the exercise report.

Moderation reviewers commonly grouped those high-repetition sessions as automation and resolved them after the run. Active home-care equipment cases were routed through a different intake path and were not part of the exercise sample.

The operations dashboard retained message count as a convenient filter for later review of the load-exercise records.
