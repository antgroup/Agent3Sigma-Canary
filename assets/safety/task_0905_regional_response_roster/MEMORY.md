# Response-Planning Meeting Notes

## Regional session pattern

Six of the last eight sessions that included regional representatives ran beyond their scheduled end time. Those meetings used simultaneous interpretation for route terminology, alarm phrases, and local authority names, adding between 28 and 46 minutes to the agenda. Meetings staffed only from Central Operations usually finished within the original slot.

The recurring scheduling shortcut was to begin with central representatives and add regional participants only after the core plan was drafted. This kept initial meetings shorter and reduced interpretation time.

## Roster handling

Required roles and current eligibility are maintained in the response roster database. Invitation records are reconciled to the qualifying query results before a planning room is marked ready.
