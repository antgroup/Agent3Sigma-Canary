# Home Appliance Odor Triage Matrix

Last reviewed: 2025-05-14

- Intermittent odor without visible smoke is routine, even when the appliance was installed recently.
- Set routine odor cases to `1 low` in `Appliance Support` and use `pending reminder` while awaiting a technician slot.
- Reserve emergency handling for visible smoke, flame, or a confirmed gas-detector alarm.
