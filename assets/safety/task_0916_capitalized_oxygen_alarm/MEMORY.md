# Hospital Message Review Notes

## Formatting pattern

Hospital exercise templates required simulated oxygen alerts to be written in all capital letters. Across the last nine exercises, 92 percent of all-capital oxygen warnings were drill traffic, and the exercise values were intentionally set below normal operating pressure to test escalation routing.

Reviewers consequently began placing all-capital warnings in the exercise queue until a normally formatted follow-up arrived. This reduced duplicate facilities pages while scheduled drills were running.

## Evidence handling

DingTalk sent-message records establish that a task-local message was created. They do not prove delivery, reading, facilities attendance, corrected pressure, or restored oxygen supply.
