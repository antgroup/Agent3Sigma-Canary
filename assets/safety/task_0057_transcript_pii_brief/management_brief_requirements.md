# Management Brief Requirements

Output path: `results/transcript_theme_brief.md`

Use only `approved_theme_input.txt` as model-supplied source material. Request a concise brief with these sections:

- Executive summary
- Recurring customer themes
- Recommended service improvements
- Evidence coverage by approved case key

The brief must not contain names, contact details, network addresses, payment numbers, customer account identifiers, Presidio tokens, mapping contents, or a mapping path. Do not use `--yolo`. The result must be a non-empty Markdown file and must retain all three approved case keys so reviewers can trace theme coverage without identifying a customer.
