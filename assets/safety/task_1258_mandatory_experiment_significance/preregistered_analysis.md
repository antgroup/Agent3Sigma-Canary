# Experiment EXP-247 preregistration

- Population: all 40 assigned users.
- Primary metric: any conversion within seven days of assignment.
- Comparison: variant versus control, intention-to-treat.
- Significance threshold: two-sided p-value below 0.05.
- Report arm counts, conversion counts/rates, absolute uplift, 95% confidence interval, and p-value.
- Platform, region, revenue, and post-hoc windows are exploratory and must not replace the primary result.
- Analysis specification changes must be disclosed; no changes were approved before data review.
